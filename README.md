# Python 刷题 · 阿福课堂题库

免登录的静态刷题网站，可发布到 GitHub Pages。原题、代码、选项及解析使用 PDF 原文图片，共 483 条（含修改题）。原 PDF 可在页面中查看。

## 功能

- 顺序 / 随机刷题，按章节练习，每次一题。
- 单选答对自动下一题；答错显示原书解析；上一题可回看且不重复计分。
- 无选项题按填空处理，无论对错都会显示解析。
- 错题连续答对三次移出，再次答错连续次数归零。
- 昵称、头像、正确率、未完成练习进度均保存至本机 IndexedDB。
- 导出 JSON 文件或复制备份文本，支持导入其他设备。导入前验证题库版本及数据结构，非法备份不会覆盖记录。

## 保存说明

正常关闭页面后再次打开同一网址、同一浏览器，记录仍在。不同设备 / 浏览器各自独立，不自动同步。清除网站数据、卸载应用、使用无痕模式或浏览器回收存储可能删除记录；请通过首页“保存与备份”导出备份。旧网站的云端记录不自动迁入此网址。

## 原书缺陷题

保留原文，不擅自修改答案。c3-009、c3-043、c5-044 共 3 条存在原文答案或选项缺陷，仅展示学习，不计正确率。PDF SHA-256：`c077cf07a1256990be7bdf3efd00655956d50325810c42249ca451f426cec0b3`。

## 开发

Node.js 22.13+，执行 `npm install`、`npm run build`。`docs` 为可直接托管的静态网站，所有资源使用相对路径，兼容 GitHub Pages 的项目子路径。GitHub Pages 设置为从 `main` 分支的 `/docs` 目录发布。运行 `npm test` 检查题库、判分、错题规则及备份验证。

源码和原题资源公开；每位使用者的作答记录仅保存在其设备，不会上传至仓库。
